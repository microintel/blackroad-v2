BLACKROAD • BROKERAGE CONNECTION SETUP

BlackRoad Brokerage Connection Setup

Connect your brokerage to BlackRoad in a few minutes. This guide uses Angel One SmartAPI: you will create your SmartAPI app, get your API key, enable TOTP with Google Authenticator, and then sign in to your brokerage from BlackRoad.

Open SmartAPI portal Enable TOTP Get Google Authenticator
Important: Keep your API key, Client ID, PIN and TOTP secret private. BlackRoad should only store credentials according to your chosen security design.
1. SmartAPI login→ 2. Create app→ 3. Copy API key→ 4. Enable TOTP→ 5. Google Authenticator→ 6. BlackRoad login→ 7. Log out safely
1

Open Angel One SmartAPI

Open the official Angel One SmartAPI developer portal in your browser.

Open SmartAPI login SmartAPI home
  • Enter your Angel One Client ID.
  • Enter your Angel One PIN.
  • Complete any OTP/validation requested by Angel One.
  • Continue to the SmartAPI dashboard.
2

Create a SmartAPI application

After logging in, find the option to create a new application/project.

Open SmartAPI dashboard
  • Choose any app name you want.
  • Enter the project/callback URL required by SmartAPI.
  • Enter the IP address requested by SmartAPI.
  • Review the information carefully.
  • Click Create.
IP address: Use the IP value required by the current SmartAPI application form and its documentation. Do not enter a random address just because this guide shows an example.
3

Copy your API key and application details

Once the application is created, open its details and copy the credentials provided by SmartAPI.

API KeyCopy from your SmartAPI app.
Client IDYour Angel One client identifier.
PINYour Angel One trading/login PIN.
Keep these ready: API Key + Client ID + PIN. You will enter them in BlackRoad.
4

Enable TOTP for Angel One

Now set up TOTP authentication for your Angel One account.

Open Enable TOTP page
  • Open the official Angel One SmartAPI TOTP setup page (button above).
  • Select Enable TOTP.
  • Enter your Client ID.
  • Enter your PIN.
  • Complete the requested OTP/validation.
  • Angel One will provide a QR code for authenticator setup.
5

Scan the QR code with Google Authenticator

Install/open Google Authenticator on your phone and add the Angel One account.

Google Play App Store
  • Open Google Authenticator.
  • Tap the + button.
  • Select the option to scan a QR code.
  • Scan the QR code shown by Angel One.
  • Google Authenticator will create a 6-digit verification code.
Never share the QR code or TOTP secret. Anyone who obtains the secret may be able to generate your verification codes.
6

Get the 6-digit TOTP

Google Authenticator continuously generates a temporary 6-digit code for your Angel One account.

  • The code changes automatically after a short period.
  • When BlackRoad asks for a TOTP, enter the currently displayed 6-digit code.
  • If the code expires, wait for the next code and enter the new one.
7

Enter everything in BlackRoad

Return to the BlackRoad app and enter the credentials you obtained above.

  • Paste your API Key.
  • Enter your Client ID.
  • Enter your PIN.
  • Open Google Authenticator and enter the current 6-digit TOTP.
  • Tap Login.
8

9

Security checklist

  • Never send your API key, PIN or TOTP secret to another person.
  • Never share screenshots containing your QR code or TOTP secret.
  • Use only the official Angel One/SmartAPI pages for account setup.
  • Do not use a sample QR code or sample 6-digit number from this guide.
  • Log out of BlackRoad when using a shared device.
!

Always log out — what happens if you don't

When you log in to Angel One, your brokerage details are turned into a JWT session token (plus refresh and feed tokens). Think of it as a digital key to your account: whoever holds it can talk to Angel One as you — without your PIN or TOTP — until it expires or you log out.

If someone finds or copies your session token, they can:

  • See your account: profile, holdings, positions, funds and order history.
  • Place, change or cancel orders in your name, if the session allows trading — this can cause real money loss.
  • Stay logged in as you in the background, with live market feed access, until the token expires.
  • Misuse your private data — portfolio details, client ID and trading patterns.

How a token ends up in the wrong hands

Shared / public deviceBrowser or app still logged in after you leave.
Screenshots & screen shareToken, API key or logs visible in an image or call.
Malware / unsafe extensionsCan read stored session data from the browser.
Pasted code & logsTokens left in chats, emails, GitHub or support tickets.

Without logout vs. with logout

Not logging out
  • Session token stays valid and usable.
  • Anyone with the device or token can act as you.
  • Possible unwanted orders and exposed account data.
Logging out
  • Session is closed and the token is invalidated.
  • A copied token is useless to anyone else.
  • Next login needs your PIN and a fresh TOTP.
If you think your session or API key was exposed: log out of BlackRoad and Angel One immediately, change your PIN, delete or regenerate the API key in the SmartAPI portal, reset TOTP, review your orders and positions, and contact Angel One support.
